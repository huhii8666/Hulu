# BlueFit

اپلیکیشن PWA فارسی برای ساخت و ذخیره برنامه تمرینی شخصی‌سازی‌شده با رابط Liquid Glass آبی روشن.

## امکانات
- رابط فارسی و راست‌چین و واکنش‌گرا
- پرسش‌نامه و ساخت برنامه پیشنهادی
- ذخیره برنامه‌ها در همان دستگاه
- PWA با قابلیت نصب
- ثبت‌نام و ورود با ایمیل، خروج از حساب و بازیابی رمز عبور با Supabase Auth
- امکان تأیید ایمیل هنگام ثبت‌نام، طبق تنظیمات Supabase

## فعال‌سازی ورود ایمیلی
1. در Supabase یک پروژه بساز.
2. در Project Settings و سپس API، مقدار Project URL و کلید عمومی anon یا publishable را بردار.
3. در فایل auth.js، مقدار YOUR_SUPABASE_PROJECT_URL و YOUR_SUPABASE_ANON_KEY را با آن‌ها جایگزین کن.
4. در Authentication و سپس URL Configuration، دامنه منتشرشده برنامه را به Site URL و Redirect URLs اضافه کن.
5. در Authentication و Providers مطمئن شو Email فعال است.

فقط کلید عمومی anon/publishable را در برنامه قرار بده؛ هرگز service_role key یا رمز دیتابیس را در کد فرانت‌اند نگذار. رمز عبور کاربران در localStorage ذخیره نمی‌شود و احراز هویت توسط Supabase انجام می‌شود.

## محدودیت فعلی
ورود ایمیلی حساب را ایجاد و احراز هویت می‌کند، اما برنامه‌های تمرینی هنوز فقط در همان دستگاه و مرورگر ذخیره می‌شوند. همگام‌سازی برنامه‌ها بین دستگاه‌ها به طراحی جداگانه دیتابیس و سیاست‌های دسترسی نیاز دارد.
