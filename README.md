# BlueFit

اپلیکیشن PWA فارسی برای ساخت و ذخیره برنامه تمرینی شخصی‌سازی‌شده با رابط Liquid Glass آبی روشن.

## اجرا

این پروژه بدون مرحله build و با فایل‌های استاتیک اجرا می‌شود. کافی است پوشه را روی هر هاست استاتیک با HTTPS منتشر کنید (برای توسعه محلی از یک static server استفاده کنید).

## امکانات نسخه اولیه

- رابط فارسی و راست‌چین، واکنش‌گرا و دارای انیمیشن نمایان‌شدن هنگام اسکرول
- پرسش‌نامه تعیین هدف، محل تمرین، سطح تجربه، تعداد روز و زمان هر جلسه
- تولید برنامه پیشنهادی قابل مشاهده
- ذخیره و حذف برنامه‌ها در localStorage مرورگر
- manifest و service worker برای نصب و دسترسی آفلاین پایه

## نکته مهم

این نسخه یک نمونه اولیه سمت‌کاربر است؛ داده‌ها فقط روی همان مرورگر/دستگاه ذخیره می‌شوند و حساب کاربری یا همگام‌سازی ابری ندارد. پیشنهادهای تمرینی عمومی‌اند و جایگزین ارزیابی متخصص ورزش یا پزشک نیستند. برای انتشار عمومی، توصیه می‌شود بانک حرکات و منطق برنامه‌سازی با مربی واجد صلاحیت بازبینی شود.
